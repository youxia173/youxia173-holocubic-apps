## 桌面使用

Windows V1.0.3：进食新增完整的透明拉面动画，饭盒与拉面每次开始时随机二选一，整轮不切换，共用进食时长和饱食恢复规则。核心吃面可循环；素材在 `预览/素材/诺诺-吃拉面动画/`，详见 `Windows吃拉面动画.txt`。

Windows V1.0.2：网页画面设置增加“其他软件全屏时取消置顶”，默认开启并保存。每半秒检测同屏前台全屏窗口（含无边框全屏），暂时取消置顶；退出全屏或切回普通窗口后恢复用户原本的置顶选择。普通最大化窗口、桌面不触发，原本关闭置顶时不会自动开启。

Windows V1.0.1 隐藏任务栏按钮，系统托盘显示诺诺图标。右键托盘图标选择“打开设置网页”可使用系统默认浏览器进入设置，选择“退出”会保存属性并关闭软件。若图标被 Windows 收起，可在任务栏的隐藏图标区域找到，并拖到常显区域。

双击软件根目录 `桌宠诺诺.exe`。右键桌宠选择“打开网页设置”或按F1。网页中选择活动并点击“播放所选活动”即可播放全流程；勾选“自动生活”并保存恢复随机活动。手动活动完整结束后也会回到待机。显式选择其他动作可以中断当前活动。

面板中“进食时长”“睡眠时长”“看书时长”“游戏时长”“撸猫时长”和“逗猫时长”独立设置5–600秒；睡眠默认60秒，其余默认30秒。设置指中间循环的时长，开始和结束动作另计；向上取整到完整循环后再自然结束。修改只在下一次对应活动开始时生效，不会截断当前动作。设置保存在`预览/用户设置.txt`，重启保留；旧版本只保存一个进食数字的文件仍可读取。

支持100%（320×240）、150%、200%（默认640×480）、300%（960×720）、400%（1280×960），透明桌面、1物理像素细线外框、默认置顶和底部带秒时钟（Windows）。拖动人物或时钟移动窗口，Esc退出。黑底选项用于设备显示参考。旧调试窗口已移除。

## 动画与衔接

- 睡眠使用`assets/nono-sleep-intro.gif`、`nono-sleep-loop.gif`、`nono-sleep-outro.gif`，分别为入睡、循环呼吸、醒来。
- 白猫待机使用`assets/nono-idle-cat.gif`。睡眠开始/结束与待机共用锚点、坐标、落地基线和调色板。循环首尾及三个阶段的衔接帧逐像素一致。
- 原视频中不自然的转身段重新生成；睡眠循环去掉意外睁眼的部分，只保留持续闭眼的呼吸动作，RIFE放慢与补帧。醒来单独生成，未用倒放睡倒的办法。
- 视频中间素材使用绿底；运行素材是真透明GIF。编码目标约32 FPS，帧延迟按GIF的10ms精度分配，实际时长写入`代码/layout.json`。
- 吃饭保留既有准备、循环进食、收拾流程。看书新增取书坐下→阅读翻页循环→合书起身收好；游戏新增取掌机坐下→按键循环→收起站立。两者准备、结束各5.53秒，核心循环每圈5.03秒；默认30秒取6圈，完整活动约41.24秒。

运行逻辑采用每活动独立的`loop_seconds`，不再把所有流程绑定到吃饭时长。Windows解码后复用循环帧，设置600秒不会复制几万张完整位图。自动活动按完整周期切换；吃饭、睡眠、看书、游戏会完成开始/循环/结束后回待机。

## HoloCubic安装

完整包：`安装包/桌宠诺诺_v1.0.5_完整安装包_网页设置版.zip`。Windows便携包：`安装包/桌宠诺诺_Windows高清版_v1.0.3_便携包.zip`。

1. 退出旧应用，解压后将ZIP中的`nono`复制到SD卡`apps`，目标为`/sd/apps/nono/main.lua`，覆盖同名程序文件。
2. 启动应用后打开设备的`/nono/`网页设置各项时长（5–600秒）。保存后下次活动生效，无需编辑文件。设备设置文件`user-settings.json`应在覆盖更新时保留。
3. 刷新列表或重启，打开诺诺。左右键手动选动作并暂停随机，下键恢复自动，上键遮挡测试，退出沿用系统操作。
4. 未校时显示`--:--`；素材出错保留时钟并显示错误。

设备每10ms累计活动计时，时钟每250ms更新；真实设备的解码帧率、内存和定时回调延迟仍需真机验证。桌面测试不代表设备性能。

## 验证与过程文件

`预览/tools/test_device.py`模拟Lua入口，检查独立时长、四种时长边界、活动不中途截断、按键、随机选择、时钟与退出清理。`预览/tools/test_animations.py`解码检查时长、透明边缘、循环及待机接点。`预览/启动预览.ps1 -Verify`检查Windows渲染、设置保存兼容、循环计时、时钟与重载。安装包校验目录、CRC、逐文件SHA-256。

关键帧、分镜、生成提示词、任务记录、视频与接点补帧保存在`预览/完整睡眠/`；不进入设备安装包。桌面`诺诺-完整睡眠动画`文件夹包含透明素材、完整示例和可切背景的本地预览页。

日程、职业、成长和持久化养成数据仍为后续工作。

看书与游戏过程文件在`预览/看书与游戏/`。本版统一待机、睡眠、看书、游戏调色板，确保软件内起止接点逐像素一致；吃饭保留既有素材。

## V1.0.0 需求驱动与 Cubic 同步
Windows 与 Cubic 使用相同规则：饱食低于30→吃饭至80，活力低于25→睡觉至85，心情低于35→随机游戏／撸猫／逗猫至80。仅低于阈值触发的自动恢复具有双倍正向增益：吃饭每秒+2饱食，睡觉每秒+1.6活力，玩耍每秒+1.6心情。普通衰减不翻倍；手动和日常活动保持原速；看书等级经验每秒+1。准备及收尾不加属性。按完整循环向上取整，收尾后可能略高于恢复目标。
多个需求同时不足，优先处理相对阈值比例最低者；完整动作结束回到待机后再处理下一个，不中途切断。健康时随机看书或玩耍，不随机吃饭或睡觉。自动恢复时长不覆盖手动时长设置。
Cubic 顶部四条属性可一直显示或数值变化后显示1–600秒（默认10秒）；底部显示秒钟、日期星期、上下班倒计时以及今日／明日天气。天气沿用 Cubic Control 天气地址及官方服务，无额外城市输入。

## Cubic V1.0.5：绕开GIF播放路径
用户反馈V1.0.4完整帧黑底GIF仍在看书结束回待机时花屏。设备端CRC核对待机/看书循环/看书结束GIF，与本地一致，排除了这些文件的上传损坏；未据此断言固件的具体故障。
设备采用 frame-layout.json、frame_player.lua 和 assets/frames/ 的独立压缩RGB565帧，不调用GIF播放器。固定200×150画布复用，先完成读取、解压、长度/矩形/CRC校验，再在一次canvas帧更新内清黑底并绘制。仅存储每帧非黑区域以降低解压量，画布原点和人物校正不变。遇到损坏帧不向画布提交，并通过网页状态提供错误和帧统计。
目标25帧/秒，保留完整动作时长；设备负载较高时按时间选择当前帧，不积压异步解码任务。Windows透明高清GIF保持不变。设备新地址 http://192.168.173.187/nono/ 。

实测记录（V1.0.5最终播放实现）：三次完整看书→待机，共约1800帧，最终验证期间 failures=0、recoveries=0，通常每帧33–35毫秒；系统繁忙时有少量跳帧。此前测试曾观测到文件 read/open 失败，因此最终实现加入失败时关闭并重新打开文件重试、数据校验通过后才提交画面。连续失败时保留上一张正确画面，超过1秒才显示错误；下一张有效帧清除错误。没有据此断言固件具体内部原因，也没有把HTTP存活当作屏幕无花屏的证明。
