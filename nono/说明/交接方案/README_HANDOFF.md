# HoloCubic 桌宠方案交接包

这是 2026-10-16 手机 ChatGPT 讨论的需求快照，供电脑 Codex 读取。

## 文件
- `HOLOCUBIC_PET_SPEC_V0_1.md`：主要需求、强制约束、模块划分及阶段规划。
- `CODEX_START_PROMPT.md`：第一条发给电脑 Codex 的工作指令。
- `assets/`：此前生成的概念图和睡眠测试 GIF。

## 使用方法
1. 电脑登录同一 ChatGPT 对话，下载 ZIP，在电脑上解压。
2. 将 `HOLOCUBIC_PET_SPEC_V0_1.md` 复制到 Codex 正在打开的项目 `docs/` 目录（没有目录可创建），将 `assets/` 放到适当的独立资源/参考目录，不要覆盖同名文件。
3. 打开电脑端 Codex，确认打开的是该 Git 仓库。
4. 将 `CODEX_START_PROMPT.md` 内容复制到 Codex 对话中，并按实际路径注明方案及素材的位置。
5. 第一轮先做只读分析和建议，不要自动提交与推送。

方案将来更新时，使用新的版本号，不要用旧版假设覆盖用户的新决定。
