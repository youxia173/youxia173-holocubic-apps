# 诺诺 V0.1.1 动画更新

待机改为真实逐帧动画：呼吸、眨眼、发梢轻摆及伙伴浮动。睡眠使用稳定睡姿的连续呼吸起伏，替换原先 6 帧、2.1 秒的跳姿势循环。

两段 GIF 均为透明背景、200×150、100 帧、每帧 40ms、25 FPS、4 秒循环；Windows 与设备共用素材和布局。保留细线外框、底部常驻时钟、默认初始科技形态。魔法睡眠仅为动画测试项。

构建：运行 `预览/tools/构建动画.ps1`，C# 生成连续变形帧，Python 仅编码 GIF。眨眼关键帧由 imagegen 生成，源图与提示词保存在说明目录。预览刷新定时器由 33ms 改为 15ms，以更密集采样动画时间线。

验证通过：两段均 100 帧、40ms 帧延迟；循环首尾像素变化不高于普通帧间最大变化的 1.5 倍；桌面待机眨眼与睡眠帧推进、透明背景、时钟跨动画切换与遮挡/缺失不消失、分钟跳转、20 次重载；Lua 模拟接口验证启动、午夜、切换、缺少 GIF API 与退出清理。安装包校验目录、CRC 和全部文件 SHA-256。

GIF 编码目标为 25 FPS，设备实际播放帧率、内存及透明解码仍需 HoloCubic 真机验证。V0.1.0 验证报告作为历史记录保留。
